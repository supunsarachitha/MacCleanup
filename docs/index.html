The workflow

You stay in the loop.

A scan only reads. Cleanup begins after you have seen the results and approved the selection.

  1. 01

    Scan

    See the size and item count for each supported location. Scanning changes nothing.

  2. 02

    Review

    Expand a category to inspect its location and a short preview of what was found.

  3. 03

    Select

    Choose categories yourself. Personal files in Downloads and Xcode Archives start unchecked.

  4. 04

    Confirm

    Check the totals in the confirmation dialog before any cleanup starts.

The app

See everything before you clean.

Each category shows its size and file count up front. Expand it to see where it lives, and choose exactly what goes. Your own files start unchecked.

What it checks

Useful targets.
Clear boundaries.

Only direct children of the listed folders are considered. The folders themselves stay in place.

  • User caches and logsBrowser caches
  • Temporary files older than 3 daysTrash
  • Xcode Derived DataHomebrew downloads
  • Xcode ArchivesOlder Downloads
  • Docker cleanup estimateVolumes are never pruned
!

Built around restraint

Personal files are out of bounds.

The safety policy rejects protected folders, system locations, libraries, and anything that is not a direct child of an approved cleanup folder. It is checked at scan time and again right before each item is removed. Symlinks are not followed, and items changed after scanning are skipped.

Downloads and Xcode Archives that you choose to clean are moved to the Trash. Other selected cache and temporary items are deleted. Docker volumes are never included.

Permissions stay optional

Full Disk Access is only needed for protected locations such as Trash and Safari cache. The rest of the scan remains available without it.

Get it

Install in a minute.

Requires macOS 14 Sonoma or later. Free and open source, with no third-party dependencies.

Download the app

  1. Download Mac-Cleanup-Assistant.dmg from the latest release.
  2. Drag Mac Cleanup Assistant to Applications.
  3. On first launch, right-click the app and choose Open.
Download the DMG ↓

The release is ad-hoc signed and not notarized, so macOS asks you to confirm the first launch. If it is blocked, use System Settings → Privacy & Security → Open Anyway.

Or build from source

Requires Xcode 16 or later.

Build a drag-to-Applications DMG ./scripts/build-installer.sh Output: build/installer/Mac-Cleanup-Assistant.dmg

Prefer Xcode? Open MacCleanup.xcodeproj, select the MacCleanup scheme and press ⌘R.
